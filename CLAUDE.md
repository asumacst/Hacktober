# ReciclaClaro — Instrucciones para Claude Code

@AGENTS.md

## Fuente común

Lee y aplica `AGENTS.md`, en esta misma carpeta. Allí están producto, alcance,
roles y personas, contratos, seguridad, validación y flujo de Git del equipo.
Mantén las instrucciones compartidas en ese archivo; no dupliques aquí su contenido.
Si la importación no se resuelve en tu entorno, abre `AGENTS.md` explícitamente
antes de trabajar.

## Uso de este repositorio

- El asistente acompaña a la persona y su rol asignado; no asumir frontend por
  utilizar Claude ni backend por utilizar Codex.
- Los documentos personales de carpetas superiores son contexto local y no deben
  sustituir decisiones compartidas o introducir otra distribución de roles.
- La rama principal es `master`, según `AGENTS.md`; no crear ni renombrar `main`.
- El acceso a herramientas no autoriza commits, push o merges por sí solo. Aplicar
  la autorización de la tarea y los límites definidos en `AGENTS.md`.

El repositorio contiene todo el contexto operativo común necesario; las propuestas
históricas de una carpeta superior son referencias opcionales, no dependencias.
